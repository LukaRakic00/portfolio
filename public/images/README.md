# Images Folder

Ovaj folder sadrži slike koje se koriste na portfolio sajtu.

## Struktura

Stavite svoje slike u ovaj folder:

- `profile.jpg` - Vaša profilna slika (preporučena veličina: 800x1000px)
- `project-1.jpg` - Slika prvog projekta (preporučena veličina: 1200x800px)
- `project-2.jpg` - Slika drugog projekta (preporučena veličina: 1200x800px)
- `project-3.jpg` - Slika trećeg projekta (preporučena veličina: 1200x800px)
- `project-4.jpg` - Slika četvrtog projekta (preporučena veličina: 1200x800px)
- `project-5.jpg` - Slika petog projekta (preporučena veličina: 1200x800px)

## Formati

Podržani formati:
- JPEG (.jpg, .jpeg)
- PNG (.png)
- WebP (.webp)

## Optimizacija

Preporučuje se optimizacija slika pre postavljanja za bolje performanse sajta.
