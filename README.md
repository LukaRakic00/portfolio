## **Overview**
This portfolio website represents my work as a **Software Engineer** with experience in developing and architecting scalable systems. Built with modern web technologies, it features a clean design, smooth animations, and bilingual support (English/Serbian).

## **Features**
- 🎨 **Modern Design**: Clean, professional interface with smooth animations
- 🌍 **Bilingual Support**: English and Serbian language support
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- ⚡ **Performance Optimized**: Fast loading times and smooth user experience
- 🎭 **Interactive Animations**: Beautiful transitions and hover effects using Framer Motion
- 🔍 **SEO Friendly**: Optimized for search engines
- 🌙 **Dark Theme**: Beautiful dark color scheme

## **Technologies**
- ⚛️ **Next.js 14**: Modern React framework for production
- 📝 **TypeScript**: Type-safe JavaScript for better code quality
- 🎨 **Tailwind CSS**: Utility-first CSS framework for rapid UI development
- 🎬 **Framer Motion**: Production-ready motion library for React
- 🗄️ **PostgreSQL**: Relational database management system
- 🔥 **Spring Boot**: Java-based framework for building microservices
- 🐳 **Docker**: Containerization platform
- ☁️ **Vercel**: Cloud platform for deployment
